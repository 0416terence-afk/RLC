交流電路的計算基礎，所有章節都會用到

一、正弦波標準形式
v(t) = Vm · sin(ωt + θ)　←　標準時域寫法 Vm　= 峰值（最大值）＝ V × √2 ≈ 1.414V V　 = 有效值（RMS）＝ Vm ÷ √2 ≈ 0.707Vm ω　 = 角頻率 ＝ 2πf　（單位：rad/s） f　 = 頻率　（單位：Hz） θ　 = 初始相位角
常用換算：f = 60Hz → ω = 2π×60 ≈ 377 rad/s　｜　f = 50Hz → ω ≈ 314 rad/s
家用電：台灣 110V / 60Hz，這個 110V 就是有效值，峰值 = 110×√2 ≈ 155.6V
二、相量（Phasor）表示
把正弦波「壓縮」成一個向量，用有效值 + 角度來表示，大幅簡化計算
時域 → 相量
v(t) = Vm·sin(ωt + θ)　⟹　V̄ = (Vm/√2)∠θ = V∠θ 範例：v(t) = 100√2·sin(ωt + 30°) 　　→ V̄ = 100∠30° V
兩種表示形式
極式：A∠θ → 乘法、除法用這個 → 模（大小）+ 角度
直角式：a + jb → 加法、減法用這個 → 實部 + 虛部
口訣：乘除用極式（角度加減）｜加減用直角式（實虛分開）
互相換算公式
直角式 → 極式：a+jb　⟹　√(a²+b²) ∠ tan⁻¹(b/a) 極式 → 直角式：A∠θ　⟹　Acosθ + jAsinθ 範例：3+j4 → √(9+16)∠tan⁻¹(4/3) = 5∠53° 範例：5∠53° → 5cos53°+j5sin53° = 3+j4

直角三角形：底邊=實部a，高=虛部b，斜邊=模A，θ=斜邊與水平夾角

三、四則運算規則
運算使用形式規則範例
乘法 ×極式A∠α × B∠β = AB∠(α+β)5∠30° × 2∠45° = 10∠75°
除法 ÷極式A∠α ÷ B∠β = (A/B)∠(α-β)10∠60° ÷ 2∠20° = 5∠40°
加法 +直角式(a+jb)+(c+jd) = (a+c)+j(b+d)(3+j4)+(1-j2) = 4+j2
減法 -直角式(a+jb)-(c+jd) = (a-c)+j(b-d)(5+j3)-(2+j1) = 3+j2
⚠️ 最常犯的錯：除以負角要注意！
V̄/Z̄ = 100∠0° ÷ 50∠-53° = 2∠(0-(-53)) = 2∠+53°　←　負負得正！
四、j 的意義與相位
操作幾何意義結果
× j相位逆時針轉 90°（超前）A∠θ × j = A∠(θ+90°)
÷ j相位順時針轉 90°（落後）A∠θ ÷ j = A∠(θ-90°)
j²-1j = √(-1)

9-1　純元件交流電路

9-1.1 純電阻R　｜　9-1.2 純電容C　｜　9-1.3 純電感L

9-1.1　純電阻電路（R）
Z̄ = R∠0°　（阻抗為純實數，無虛部） Ī = V̄/Z̄ = V̄/R 相位差 θ = θV - θI = 0° 特性：電阻值不受頻率影響
V 與 I 同相位——電壓和電流同時達到最大值、同時過零點
例題
已知：V̄ = 100∠30° V，R = 50Ω Z̄ = 50∠0° Ω Ī = 100∠30° ÷ 50∠0° = 2∠30° A 相位差 = 30° - 30° = 0°　✓ 同相
9-1.2　純電容電路（C）
Xc = 1/(ωC) = 1/(2πfC)　（單位：Ω） Z̄ = Xc∠-90° = -jXc Ī = V̄/Z̄　⟹　電流角度 = 電壓角度 + 90° 相位差 θ = -90°
I 超前 V 90°
電容像彈簧，電流先衝進去充電，電壓後到
頻率Xc狀態
f = 0（直流）→ ∞開路
f 越高越小越易通
f → ∞→ 0短路
例題
已知：V̄ = 100∠0° V，Xc = 25Ω Z̄ = 25∠-90° Ω Ī = 100∠0° ÷ 25∠-90° = 4∠+90° A 相位差 = 0° - 90° = -90°　✓ I超前V
9-1.3　純電感電路（L）
XL = ωL = 2πfL　（單位：Ω） Z̄ = XL∠+90° = jXL Ī = V̄/Z̄　⟹　電流角度 = 電壓角度 - 90° 相位差 θ = +90°
V 超前 I 90°
電感像慣性水輪，施壓後電流慢慢才增加
頻率XL狀態
f = 0（直流）= 0短路
f 越高越大越難通
f → ∞→ ∞開路
三種純元件對比總表
元件阻抗電抗公式相位差θV與I直流
純RR∠0°（不變）0°同相正常
純CXc∠-90°Xc=1/(ωC)-90°I超前V開路
純LXL∠+90°XL=ωL+90°V超前I短路
⚠️ C和L完全相反：直流C開路L短路；頻率越高Xc越小XL越大；C讓I超前，L讓V超前

9-4　RLC 串聯電路

XL 和 Xc 方向相反，互相抵消，看誰大決定性質

完整公式
淨電抗 = XL - Xc　←　最關鍵！正→電感性，負→電容性 Z̄ = R + j(XL - Xc) |Z| = √(R² + (XL-Xc)²) Z̄角度 = tan⁻¹((XL-Xc)/R)　（正→電感，負→電容） Ī = V̄ / Z̄ V̄R = Ī × R∠0° V̄L = Ī × XL∠+90°　（超前I 90°） V̄C = Ī × Xc∠-90°　（落後I 90°） V = √(VR² + (VL-VC)²) 分壓定則：V̄x = V̄ × (Z̄x / Z̄T)
條件淨電抗Z̄角度電路性質相位諧振
XL > Xc正值，↑正角 +θ電感性V超前I-
XL = Xc0，互消0°純電阻性V與I同相串聯諧振！Z=R（最小），電流最大
XL < Xc負值，↓負角 -θ電容性I超前V-
例題
已知：V̄=100∠0° V，R=30Ω，XL=60Ω，Xc=20Ω ①　XL-Xc=60-20=40Ω（正→電感性） ②　|Z|=√(30²+40²)=√2500=50Ω　（3-4-5三角形） ③　角度=+53°　→　Z̄=50∠53° Ω ④　Ī=100∠0°÷50∠53°=2∠-53° A ⑤　V̄R=2∠-53°×30∠0°=60∠-53° V ⑥　V̄L=2∠-53°×60∠90°=120∠37° V ⑦　V̄C=2∠-53°×20∠-90°=40∠-143° V
常考！3-4-5系列：R=30,X=40,Z=50（角53°）｜R=40,X=30,Z=50（角37°）｜R=6,X=8,Z=10｜R=5,X=12,Z=13

9-5　RC 並聯電路

並聯電路改用導納 Ȳ 計算，電壓相同，電流分配

導納概念與公式
導納 Ȳ = 1/Z̄（單位：西門子 S）是阻抗的倒數，並聯電路用這個計算最方便
G = 1/R　（電導，S） Bc = 1/Xc = ωC　（電容納，S） Ȳ = G - jBc　（直角式） |Ȳ| = √(G² + Bc²) Ȳ角度 = -tan⁻¹(Bc/G)　（負角） ĪR = V̄ × G　（與V同相） ĪC = V̄ × Bc∠+90°　（超前V 90°） |Ī| = √(IR² + IC²) 電容性：I超前V，0°~+90°
並聯方向：G往右，Bc往上（+j）——注意！Bc往上，和串聯Xc往下相反！
例題
已知：V̄=100∠0° V，R=50Ω，Xc=25Ω ①　G=1/50=0.02S，Bc=1/25=0.04S ②　|Ȳ|=√(0.02²+0.04²)=√0.002≈0.0447S ③　ĪR=100×0.02=2∠0° A ④　ĪC=100×0.04∠90°=4∠90° A ⑤　|Ī|=√(2²+4²)=√20≈4.47 A 電容性，I超前V

9-6　RL 並聯電路

並聯電路用導納 Ȳ 計算

公式
G = 1/R　（S） BL = 1/XL = 1/(ωL)　（電感納，S） Ȳ = G - jBL　（直角式） |Ȳ| = √(G² + BL²) ĪR = V̄ × G　（與V同相） ĪL = V̄ × BL∠-90°　（落後V 90°） |Ī| = √(IR² + IL²) 電感性：I落後V，0°~-90°
並聯方向：G往右，BL往下（-j）——注意！BL往下，和串聯XL往上相反！
例題
已知：V̄=120∠0° V，R=40Ω，XL=30Ω ①　G=1/40=0.025S，BL=1/30≈0.0333S ②　ĪR=120×0.025=3∠0° A ③　ĪL=120×0.0333∠-90°=4∠-90° A ④　|Ī|=√(3²+4²)=5 A　（3-4-5！） 電感性，I落後V

9-7　RLC 並聯電路

最完整的並聯電路，三支路電流合成

完整公式
G=1/R，BL=1/XL，Bc=1/Xc=ωC Ȳ = G + j(Bc - BL) |Ȳ| = √(G² + (Bc-BL)²) ĪR = V̄×G∠0°　（與V同相） ĪL = V̄×BL∠-90°　（落後V 90°） ĪC = V̄×Bc∠+90°　（超前V 90°） Ī = ĪR + ĪL + ĪC　（相量和） 分流定則：Ī₁ = Ī × Z̄₂/(Z̄₁+Z̄₂)
條件Bc-BL性質相位諧振
Bc > BL正值，↑電容性I超前V-
Bc = BL0，互消純電阻性I與V同相並聯諧振！Y=G（最小），阻抗最大
Bc < BL負值，↓電感性I落後V-
例題
已知：V̄=100∠0° V，R=10Ω，XL=5Ω，Xc=10Ω ①　G=0.1S，BL=0.2S，Bc=0.1S ②　Bc-BL=0.1-0.2=-0.1S（負→電感性） ③　|Ȳ|=√(0.1²+0.1²)=0.1√2≈0.1414S ④　ĪR=100×0.1=10∠0° A ⑤　ĪL=100×0.2∠-90°=20∠-90° A ⑥　ĪC=100×0.1∠90°=10∠90° A ⑦　|Ī|=100×0.1414=14.14 A BL(0.2)>Bc(0.1)→電感性，I落後V

10-1　瞬間功率 p(t)

交流電路中每一瞬間的功率值

公式
p(t) = VI cosθ · [1-cos(2ωt)] + VI sinθ · sin(2ωt) Pmax = VI(1 + cosθ) Pmin = VI(cosθ - 1) fp = 2f　←　瞬間功率頻率是電源的2倍！
⚠️ 常考：電源f=60Hz → 瞬間功率fp=120Hz；電源f=50Hz → fp=100Hz
例題
已知：V̄=50∠-30°V，Ī=2∠30°A，f=60Hz ①　θ=θV-θI=-30°-30°=-60° ②　VI=50×2=100 ③　Pmax=100×(1+cos60°)=100×1.5=150W ④　Pmin=100×(cos60°-1)=100×(-0.5)=-50W ⑤　fp=2×60=120Hz

10-2　平均功率 P（實功率）

單位：瓦特 W，電路真正消耗的功率

公式
P = VI · cosθ　（最通用） P = I²R　（串聯或純R） P = V²/R　（純R） P = V²G　（並聯，G=1/R） θ = θV - θI　（電壓角減電流角）
只有R消耗P！純L和純C：P=0（只是借用能量，會還回來）
例題
已知：V̄=100∠0°V，R=30Ω，XL=40Ω（RL串聯） ①　|Z|=50Ω，θ=+53°，I=100/50=2A ②　P=I²R=4×30=120W 或　P=VIcosθ=100×2×cos53°=200×0.6=120W ✓

10-3　視在功率 S

單位：伏安 VA，電源供應的全部功率

公式
S = VI　（最通用） S = I²|Z|　（串聯） S = V²/|Z|　（串聯） S = V²|Y|　（並聯） S = √(P² + Q²)
S是設備的「額定容量」，如10kVA的變壓器，S代表電源必須提供的總功率

10-4　虛功率 Q

單位：乏 VAR，儲存在電感/電容中的能量往返

公式
Q = VI · sinθ　（最通用） Q = I²X　（X為電抗值） QL = I²XL　（電感虛功，Q為正值） QC = -I²Xc　（電容虛功，Q為負值） Q = √(S² - P²)
電感性：Q > 0（正值）
電感吸收虛功率
功率三角形往上
電容性：Q < 0（負值）
電容發出虛功率
功率三角形往下

10-5　功率因數 PF

無單位，表示電能有效利用程度，越高越好

公式
PF = cosθ = P/S = R/|Z|（串聯）= G/|Y|（並聯） 範圍：0 ≤ PF ≤ 1 「超前」= 電容性（I超前V，θ<0） 「落後」= 電感性（V超前I，θ>0）
PF=1

θ=0°，P=S，Q=0
PF=0.8

θ=37°，常見
PF=0

10-6　複數功率與功率三角形

P、Q、S 的關係——功率三角形

功率三角形

P（底邊）、Q（直角邊）、S（斜邊）— 結構和阻抗三角形相同！

S̄ = P + jQ　（複數功率，VA） |S̄| = S = √(P²+Q²) 電感性：S̄ = P + jQL　（Q正，三角形往上） 電容性：S̄ = P - jQC　（Q負，三角形往下）

10-7　功率因數改善

並聯電容器，提升PF，減少線路電流

為什麼要改善PF？
PF低 → 相同P需要更大S → 電流I更大 → 線路損失I²R更多 → 電費貴、設備過熱
改善方法：在電感性負載旁並聯電容器，用電容的負Q去抵消電感的正Q
公式與步驟
Qc = P · (tanθ1 - tanθ2) C = Qc / (ωV²) = Qc / (2πfV²) θ1 = cos⁻¹(PF1)　（原始角度） θ2 = cos⁻¹(PF2)　（目標角度）
1
算θ1=cos⁻¹(PF1)，找tanθ1
2
算θ2=cos⁻¹(PF2)，找tanθ2
3
Qc=P(tanθ1-tanθ2)　→　需補多少VAR
4
C=Qc/(ωV²)，ω=2πf
改善PF的好處：①增加系統供電能力 ②減少線路電流 ③節省電費 ④減少線路損失
例題
已知：P=10kW，PF1=0.6落後，改善至PF2=0.9落後，V=220V，f=60Hz ①　θ1=cos⁻¹(0.6)=53°，tanθ1=4/3≈1.333 ②　θ2=cos⁻¹(0.9)≈26°，tanθ2≈0.484 ③　Qc=10000×(1.333-0.484)=10000×0.849≈8490VAR ④　C=8490/(377×220²)=8490/18226740≈466μF

⚠️ 最常犯的6個錯誤
